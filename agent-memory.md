



【常见的裁剪策略】

策略 1：滑动窗口 (最简单)
   保留 system + 最近 N 轮，丢弃最早的消息
   ⚠️ 注意：如果丢弃的消息里有 tool_calls，必须把对应的 tool 结果也一起丢！

策略 2：摘要压缩
   把前 20 轮对话压缩成一段摘要，替换原始消息：
   messages = [
     {"role": "system", "content": "..."},
     {"role": "user", "content": "[历史摘要] 用户之前询问了北京天气(晴25度)和穿搭建议(短袖)..."},
     {"role": "user", "content": "那明天呢？"}
   ]

策略 3：只保留关键工具结果
   丢弃中间的"模型思考过程"，只保留最终回答和关键数据。



┌─────────────────────────────────────────────────────────┐
│                                                         │
│   messages 数组 = 模型的"全部记忆"                       │
│                                                         │
│   顺序 = 时间线 = 因果逻辑                               │
│                                                         │
│   打乱顺序 = 让模型"穿越" = 产生幻觉/报错                 │
│                                                         │
│   铁律：                                                 │
│   1. system 在最前                                      │
│   2. 按时间顺序排列                                     │
│   3. tool 结果紧跟 tool_calls                           │
│   4. id 必须一一对应                                    │
│   5. 裁剪时以"轮"为单位，整进整出                        │
│                                                         │
└─────────────────────────────────────────────────────────┘
